## Estructura del repositorio

| Archivo | Contenido |
|---|---|
| `README.md` | Carátula, registro de versiones, índice y Student Outcome. Documento principal. |
| `chapters/` | Un archivo por capítulo del informe. |
| `assets/img/` | Imágenes: capturas, diagramas exportados, fotos del equipo, logos. |
| `assets/diagrams/` | Fuentes editables de los diagramas (`.drawio`, `.puml`, `.mmd`). |
| `tools/build.py` | Genera el índice y compila `informe-completo.md` para exportar a PDF. |
| `CONTRIBUTING.md` | GitFlow, Conventional Commits y flujo de trabajo del informe. |

## Cómo generar el informe completo

```bash
python tools/build.py toc     # regenera el índice dentro del README
python tools/build.py         # arma informe-completo.md uniendo README + capítulos
```

Para el PDF de la entrega, exportar `informe-completo.md` respetando la nomenclatura del
enunciado: `upc-pre-202620-1asi0732-<NRC>-<startup>-report-tf.pdf`
